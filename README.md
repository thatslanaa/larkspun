# Larkspun

Hum a melody into your phone and get it back as an arranged, produced song.

**Open it:** https://thatslanaa.github.io/larkspun/

This repository holds only the built website (one page plus icons). It runs entirely in the visitor's browser: no server, no account, no cookies, no analytics. Built from the private Larkspun project (`browser/build.py --site`).
